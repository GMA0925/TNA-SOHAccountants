## Response Checklist

When you receive an error email:

- [ ] Check timestamp - is this happening now?
- [ ] Check location - what component failed?
- [ ] Check user - is this affecting one user or many?
- [ ] Check IP - is this an internal or external user?
- [ ] Check stack trace - what's the root cause?
- [ ] Check inner exception - what really failed?
- [ ] Notify development team
- [ ] Create issue in tracking system
- [ ] Monitor for similar errors
- [ ] Deploy fix when ready
