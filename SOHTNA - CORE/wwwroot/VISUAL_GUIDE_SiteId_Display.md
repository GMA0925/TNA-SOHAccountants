## What the SiteId Number Means

```
? SiteId 1: 5 new employees created
   ?????????????
         ?
    This number identifies:
    • Which site's ReaderEvents were queried
    • Which site the new employees belong to
    • Which site to check if there's an error
    
    Value comes from: Session["SiteId"]
    Set during: User Login (Login.aspx.cs)
    Stored in: Users.SiteId (database)
```

---

## Persistence of Message

**Message Persists Until:**
1. User performs another action (Save, Edit, Delete)
2. User filters status (dropdown changes)
3. User navigates to different page
4. Page is manually refreshed

**Message stays visible:**
- Allows user to review what happened
- Shows SiteId clearly for verification
- Remains until replaced by next action message

---

## Quick Troubleshooting with Visual Display

### I see "SiteId 2" but expected "SiteId 1"
? Check your login - you're logged in as Site 2 user

### I see "No new employees found" but expect employees to sync
? ReaderEvents for this SiteId might already exist as Employees

### I see an error message
? Copy the full error message including SiteId for support

### Message appeared then disappeared
? Another action was performed (page might have auto-loaded data)

## Development Note

**The SiteId display is implemented in:**
- File: `EmployeeEnrollment.aspx.cs`
- Method: `SyncReaderEventsToEmployees()`
- Control: `lblMessage` (label control on aspx page)

**Three display points:**
1. **Start:** Line 22-23 (blue syncing message)
2. **Success:** Line 76-85 (green result message)
3. **Error:** Line 89-92 (red error message)

All three include the `parsedSiteId` value for visibility.
