```

```

### **Step 2: View Statistics**
```
See real-time counts at top:
- Present count & percentage
- Absent count & percentage
- Leave count & percentage
- Late arrivals count & percentage
```

### **Step 3: Search Attendance**
```
1. Set Start Date & End Date
2. Select Department (optional)
3. Select Employee (optional)
4. Select Status (optional)
5. Click "Search"
6. View results in grid
```

### **Step 4: Add Records**
```
1. Select Employee
2. Select Date
3. Select Status
4. Enter Time In (optional)
5. Enter Time Out (optional)
6. Enter Hours Worked
7. Enter Late Minutes (if applicable)
8. Enter Remarks (optional)
9. Click "Add Attendance"
```

### **Step 5: Export Data**
```
Click "Export Attendance to Excel" OR
Click "Export Trends to Excel"
File downloads automatically
```
