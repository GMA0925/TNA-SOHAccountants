## Version Display Behavior

### On Page Load
```
Step 1: Page loads
        ?
Step 2: Page_Load event fires
        ?
Step 3: Code retrieves assembly version
        ?
Step 4: Version formatted as "v1.0.0.0"
        ?
Step 5: Version displayed in lblVersion
        ?
Step 6: User sees version below logout button
```

### Runtime Example
```
Assembly Version: 1.0.0.0
Display Format:   v1.0.0.0
Location:         Header, below logout
Retrieval:        Automatic
Updates:          Changes with AssemblyInfo.cs
```
