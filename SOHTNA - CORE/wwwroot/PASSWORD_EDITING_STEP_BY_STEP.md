## ?? **Common Scenarios:**

### **Scenario 1: User Forgets Password - Admin Changes It**
```
Step 1: Click Edit on user's row
Step 2: Type new temporary password
Step 3: Click Update
Step 4: ? Password changed - user gets temp pwd via email
Result: User can now login with new password
```

### **Scenario 2: Update User Info, Don't Change Password**
```
Step 1: Click Edit on user's row
Step 2: Change email/role/status
Step 3: Leave password field BLANK
Step 4: Click Update
Step 5: ? User info updated - password unchanged
Result: User can still login with old password
```

### **Scenario 3: User Changes Own Password**
```
Step 1: Click Edit on own user row
Step 2: Type new secure password
Step 3: Click Update
Step 4: ? Password changed securely
Result: User can login with new password next time
```
